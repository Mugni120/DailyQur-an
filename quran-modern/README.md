# Al-Qur'an Modern PRO

Website Al-Qur'an digital modern, elegan, dan profesional yang dilengkapi:
1. **114 Surah Lengkap**: Direktori seluruh surah Al-Qur'an dari Al-Fatihah sampai An-Nas beserta informasi tempat turun (Makkiyyah/Madaniyyah), jumlah ayat, nomor juz, dan keutamaan/asbabun nuzul.
2. **Penjelasan & Deteksi Tajwid Interaktif**:
   - Hukum Nun Mati & Tanwin (Idzhar, Idgham Bighunnah/Bilaghunnah, Iqlab, Ikhfa)
   - Hukum Mim Mati (Ikhfa Syafawi, Idgham Mimi, Idzhar Syafawi)
   - Hukum Mad (Thabi'i, Wajib Muttashil, Jaiz Munfashil, dll.)
   - Hukum Qalqalah (Sughra, Kubra, Akbar)
   - Ghunnah Musyaddadah
   - Ensiklopedi kaidah tajwid & Kuis Uji Tajwid interaktif
3. **Hadist-Hadist Shahih Terkait**:
   - Keutamaan membaca & menghafal Al-Qur'an
   - Mahkota kemuliaan orang tua hafidz
   - Pahala 10 kebaikan tiap huruf
   - Syafaat hari kiamat
   - Keutamaan surah pilihan (Al-Kahfi, Al-Mulk, Al-Ikhlas, Ayat Kursi, dll.)
4. **Suara dari 7 Tokoh Islam Terkemuka**:
   - Syaikh Misyari Rasyid Al-'Afasy (Kuwait)
   - Syaikh Mahmud Khalil Al-Hushary (Mesir)
   - Syaikh Abdur-Rahman As-Sudais (Arab Saudi)
   - Syaikh Sa'ad Al-Ghamdi (Arab Saudi)
   - Syaikh Abdul Basit Abdul Samad (Mesir)
   - Syaikh Saud Asy-Syuraim (Arab Saudi)
   - Syaikh Maher Al-Muaiqly (Arab Saudi)
   - Fitur Repeat Mode untuk muraja'ah hafalan & pengaturan kecepatan tilawah
5. **Fitur Latihan Hafidz (Hifz Memorization Suite)**:
   - Sambung Lanjutan Ayat (Tebak ayat berikutnya dengan streak & skor)
   - Susun Kata Ayat (Word Scramble puzzle kata Arab)
   - Mode Hafalan Teks (Blur / Peek mode intip 2 detik)
   - Target & Tracker Hafalan (Checklist 114 surah status Mutqin)
6. **Desain UI/UX Modern & Profesional**:
   - Tema Gelap (Dark), Terang (Light), dan Sepia
   - Tipografi Arab Amiri berdefinisi tinggi
   - Responsif di HP, Tablet, dan Laptop/Desktop

## Cara Menjalankan
Buka file `index.html` dengan browser Google Chrome, Mozilla Firefox, Safari, atau Microsoft Edge.
Atau jalankan web server:
```bash
python3 -m http.server 8000
```
Lalu kunjungi http://localhost:8000.
